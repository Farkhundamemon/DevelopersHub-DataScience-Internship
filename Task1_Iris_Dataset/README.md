#  Task 1 - Iris Dataset Analysis

## 📌 Overview
This project focuses on performing Exploratory Data Analysis (EDA) 
on the Iris dataset using Python. The goal is to understand data 
patterns, relationships, and distributions through visualization.

## 🎯 Objective
- Explore dataset structure
- Analyze feature relationships
- Visualize distributions
- Identify patterns and insights

## 🛠 Tools Used
- Python 3.14
- VS Code
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## 📂 Dataset
The Iris dataset contains 150 samples of iris flowers with the 
following features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## 🔍 Analysis Performed
- Data inspection using .shape, .info() and .describe()
- Scatter plots for feature relationships
- Histograms for distribution analysis
- Boxplots for outlier detection

## 🧠 Key Insights
- Dataset has no missing values
- Virginica has the largest sepal length
- Setosa is clearly separable from other species
- Petal features are more useful for classification

## ✅ Conclusion
Iris dataset is simple yet powerful for understanding exploratory 
data analysis. Visualizations reveal that Setosa species is clearly 
separable from others making this dataset ideal for beginners in 
Machine Learning.
